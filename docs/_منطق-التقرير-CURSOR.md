# منطق تقرير التقييم العقاري — مواصفة للتطوير (Cursor Handoff)

مرجع: `تقرير التقييم v3.dc.html` — نموذج تقرير تقييم عقاري (20 صفحة A4) لشركة إجادة المهنية للتقييم، متوافق مع معايير التقييم الدولية IVS 2025 ومتطلبات الهيئة السعودية للمقيمين المعتمدين (تقييم).

---

## 1. نظرة عامة

- **المستند:** تقرير تقييم مفصل، RTL عربي، A4، كل صفحة على ترويسة إجادة الرسمية (letterhead PNG خلفية كاملة).
- **الحالة الحالية:** بيانات نموذجية (فيلا سكنية، جدة/الصوارى) — الهدف ربطها بمصدر بيانات حقيقي.
- **الأسلوبان المستخدمان في النموذج:** السوق (المقارنة) + التكلفة (الإحلال). أسلوب الدخل غير مستخدم — صفوفه تُحذف شرطيًا.
- **أساس القيمة:** قيمة التصفية (تصفية منظمة) — يُطبق خصم تصفية على القيمة المرجحة.

## 3. منطق الحسابات (Business Logic)

### 3.1 أسلوب السوق — طريقة المقارنة (قسم 17 + 19)
لكل عقار مقارن (3 مقارنات):
```
سعر_المتر = السعر ÷ مساحة_الأرض
سعر_بعد_تسوية_السوق = سعر_المتر × (1 + تسوية_التمويل٪ + تسوية_ظروف_السوق٪)
سعر_بعد_التسويات = سعر_بعد_تسوية_السوق × (1 + تسوية_المساحة٪ + تسوية_الموقع٪ + تسوية_الشوارع٪)
```
ثم:
```
المتوسط_المرجح = Σ(سعر_بعد_التسويات_i × الوزن_i)      // Σ الأوزان = 100٪
قيمة_المقارنة = المتوسط_المرجح × مساحة_أرض_العقار
```
قواعد عرض:
- نوع العملية: «صفقة منفّذة» أو «عرض / حد|سوم / المنصة / رقم الإعلان / الجوال».
- تسوية بلا قيمة تُعرض «٪» فقط (فارغة).
- المتوسط المرجح في النموذج مُقرّب لعرضه (3,825.00) — التحقق: 3866.31×0.4 + 3858.66×0.3 + 3736.26×0.3 = 3825.00.
- **مبررات التسويات إلزامية:** بند لكل تسوية غير صفرية (حد → سالب لأنه سقف بائع، سوم → موجب لأنه عرض مشترٍ، قدم الصفقة → موجب مع صعود المؤشر).

### 3.2 أسلوب التكلفة (أقسام 20–23)
```
قيمة_الأرض = سعر_متر_الأرض × مساحة_الأرض
// سعر متر الأرض من مقارنات أراضٍ شاغرة — ليس من مقارنات الفلل

التكلفة_المباشرة = Σ(مسطح_i × سعر_متر_i) + Σ(بنود_مقطوعية)   // سور، مواقف، خزانات، تشجير
التكلفة_الإجمالية = التكلفة_المباشرة × (1 + مجموع_النسب_غير_المباشرة)
// غير مباشرة: تصميم 4٪ + ترخيص 2٪ + إدارة 3٪ + طوارئ 2٪ + أرباح مطور 4٪ = 15٪

التقادم_المادي = العمر_الفعلي ÷ العمر_الاقتصادي            // 10/40 = 25٪
مجموع_التقادم = مادي + وظيفي + خارجي
الإهلاك = التكلفة_الإجمالية × مجموع_التقادم
قيمة_المباني = التكلفة_الإجمالية − الإهلاك
ناتج_أسلوب_التكلفة = قيمة_الأرض + قيمة_المباني
```

### 3.3 الترجيح والقيمة النهائية (أقسام 24–25)
```
القيمة_المرجحة = Σ(ناتج_الأسلوب_i × نسبة_المشاركة_i)        // Σ = 100٪
قيمة_العقار = القيمة_المرجحة × (1 − خصم_التصفية٪)          // 1,514,000 × 0.8 = 1,211,200
القيمة_النهائية = تقريب(قيمة_العقار) لأقرب ألف (نزولًا)      // 1,211,000
```
- مبرر معامل التصفية نص إلزامي بجوار النسبة (سيولة المنطقة، فترة تسويق ≤ 90 يومًا).
- القيمة النهائية تُعرض رقمًا + **تفقيطًا** («فقط مليون ومئتان وأحد عشر ألف ريال سعودي لا غير») في شريط كحلي #102b4e.

### 3.4 قواعد شرطية
- **أساليب غير مستخدمة:** لا تُعرض صفوفها في جدول الترجيح؛ في قسم 16 تُكتب «غير مستخدم».
- **الختم:** `showStamp` (boolean prop, افتراضي false) يُظهر/يخفي صورة الختم في خلية «ختم المنشأة».
- **المنقولات:** إن «لا» → الوصف «لا يوجد منقولات بالعقار».
- عدادات الخدمات: عدد + قائمة أرقام مفصولة بـ «·».

## 4. قواعد التنسيق (Formatting Rules)

- **الأرقام:** لاتينية، `tabular-nums`، فواصل آلاف، منزلتان عشريتان للمبالغ (1,444,000.00)، النسب «2.00٪».
- **الأرقام والإحداثيات داخل خلايا:** `direction:ltr; unicode-bidi:isolate` — يضمن موضع الإشارة السالبة والفاصلة (-3.00٪ ، 21.800029, 39.093016).
- **التواريخ الهجرية:** البادئة «هـ» تلتصق يسار التاريخ: `هـ‎1437/03/02` (مع LRM بعد هـ).
- **التواريخ الميلادية:** YYYY/MM/DD.
- **العملة:** «ر.س.» بعد الرقم.
- **الحقول الفارغة:** شرطة «-».

## 5. نظام التصميم (Ejadah DS)

- **الألوان:** كحلي `#102b4e` (عناوين، شارات الأرقام، شريط القيمة النهائية فقط)، ذهبي `#a4906f` (خط سفلي لرؤوس الجداول 2px، شريط جانبي 3px للعناوين)، كريمي `#f5f3ee` (خلفيات العناوين والخلايا المفتاحية)، حدود `#ddd8cc`.
- **الخط:** IBM Plex Sans Arabic؛ عنوان قسم 12px/700، h3 10.5px، جدول 9.5px (tight: 9px)، نص 9.5px وزن 500، line-height 1.85.
- **العناوين:** h2 = خلفية كريمية + شارة رقم كحلية (01–38) + شريط ذهبي بادئ.
- **الجداول:** `td.k` مفتاح (كريمي، عرض المحتوى)، `td.v` قيمة، `.mx` مصفوفة (توسيط)، `.sub` صف فرعي مظلل، `.total` صف إجمالي (حد ذهبي علوي 2px).
- **الصفحة:** padding `46mm 16mm 32mm 16mm` (يحترم الترويسة)، الميتا `top:13mm; right:19mm`، رقم الصفحة `bottom:22.5mm`.

## 7. ثوابت لا تتغير بين التقارير

- أقسام 04، 05، 12 (وصف مستويات التشطيب)، 28، 31، 32، 37، 38 — نصوص قانونية/تعريفية ثابتة.
- صلاحية التقرير: 90 يومًا من تاريخ التقرير (يُحقن التاريخ في نص القسم 31).

## 8. قواعد تحقق (Validation)

- Σ أوزان المقارنات = 100٪ ، Σ نسب مشاركة الأساليب = 100٪.
- مجموع مسطحات البناء = Σ الأدوار.
- ناتج كل أسلوب مستخدم > 0، وكل تسوية غير صفرية لها مبرر.
- التقادم المادي = العمر الفعلي ÷ الاقتصادي (تحذير عند الاختلاف).
- القيمة النهائية = تقريب لأقرب ألف + تفقيط مطابق.
