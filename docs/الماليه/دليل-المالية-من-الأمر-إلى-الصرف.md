# دليل المالية — من أمر العمل إلى الصرف والإيراد

> **لمن هذا الملف؟** لموظف المالية والمدير المالي ومن يريد فهم النظام **بدون قراءة الكود**.  
> **ماذا يشرح؟** كيف تصل المعاملة من إنفاذ → أمر عمل → دراسة وتنفيذ → ثم ما تفعله المالية (صرف + فوترة).  
> **الشاشة الرئيسية للمالية:** «التقارير المالية / الإدارة المالية» في النظام.

---

## 1) الفكرة من الآخر — بجملة واحدة

النظام يمرّر كل عقار داخل **أمر عمل** قادم من إنفاذ. بعد ما يكتمل العمل (معاينة / رفع / مراجعة…) تُسجَّل **أتعاب الأطراف** (تكلفة على الشركة)، وبعد ما تكتمل أو تُغلق كل المعاملات في الأمر تظهر **فاتورة إنفاذ** (إيراد للشركة). المالية لا تنشئ العمل؛ هي **تُفوتر وتصرف وتحصّل** بعد أن يعتمد المشرف والطرف مراحلهم.

| الاتجاه | الاسم في النظام | المعنى البسيط |
|--------|------------------|---------------|
| **صادر** | فوترة الأطراف / كشف فوترة | ندفع (أو نلتزم بدفع) لمعاين، مكتب هندسي، مراجع… |
| **وارد** | فوترة إنفاذ | نصدر فاتورة لإنفاذ ونسجّل التحصيل |

**هامش المعاملة** ≈ ما دخل من إنفاذ − ما التزمنا به / صرفناه للأطراف.

---

## 2) ما هو «أمر العمل»؟ (ليس أمر شراء محاسبي)

في هذا النظام **أمر العمل** = ملف التعميد من إنفاذ (PO) الذي يجمع عدة عقارات/صكوك تحت رقم واحد.

| ما تراه في الأمر | المعنى |
|------------------|--------|
| رقم الأمر (PO) | المرجع المشترك مع إنفاذ والفرق |
| نوع التعميد | تنفيذ · تركات · قطاع خاص |
| تاريخ التعميد / الاستلام | متى صدر ومتى دخل النظام |
| أخصائي التعيين | من يتابع الأمر تشغيلياً |
| عدد العقارات المتوقع · الموعد · المنطقة | إطار التخطيط |
| الوصف | ملاحظات أمر العمل |

### حالة أمر العمل (قائمة الأعمال)

| الحالة | المعنى التشغيلي |
|--------|-----------------|
| **جديدة** | دخلت، الدراسة والعمليات ما زالت في البداية |
| **تحت الدراسة** | العقارات تُدرس وتُوزَّع مهامها |
| **مكتمل** | كل صكوك الأمر دُرست/أُغلقت **بدون** فاتورة إنفاذ بعد |
| **مفوتر جزئي** | جزء من الأمر دُرج في فواتير إنفاذ |
| **مفوتر بالكامل** | الأمر مغطى فوترة إنفاذ |
| **ملغى / متوقف** | أُوقف أو أُلغي يدوياً |

> أمر العمل **ليس** شاشة مالية. هو «الوعاء» الذي يغذي المالية لاحقاً. شاشة الأوامر عند دراسة الحالة / التشغيل؛ شاشة المالية للصرف والإيراد.

## 3) كيف يتهيأ النظام للمالية؟ (قبل أن تفتح شاشة المالية)

```
إنفاذ يعمّد → يُسجَّل أمر عمل + عقارات
     ↓
دراسة حالة لكل صك / عقار
     ↓
مهام تنفيذ: معاينة ميدانية · رفع مساحي · مراجعة حكومية
     (+ أتعاب زيارة محكمة / مفاتيح عند اللزوم)
     ↓
يكتمل العمل → يُنشأ «سجل أتعاب» للطرف (مستحق / مسودة)
     ↓
المشرف يعالج الحسم والاعتماد → يصل «جاهز للفوترة»
     ↓
المالية: كشف فوترة أطراف → إصدار → صرف/إغلاق
```

وبالتوازي، عندما **تكتمل أو تُلغى كل معاملات الأمر**:

```
أمر العمل جاهز لفوترة إنفاذ
     ↓
المالية تعبّئ بنود الإيراد لكل عقار → تصدر فاتورة (+ ضريبة) → تسجّل التحصيل
```

### متى يظهر «مستحق» عند الطرف؟

| نوع العمل | متى يُسجَّل الأتعاب تقريباً |
|-----------|------------------------------|
| معاينة ميدانية / مراجعة حكومية | بعد اكتمال دراسة الحالة للصك وارتباط المهمة |
| رفع مساحي (مكتب هندسي) | عند **قبول** مخرجات الرفع (ليس مجرد الرفع) |
| مفاتيح / زيارة محكمة | مسارات منفصلة؛ إيراد المفاتيح يدخل غالباً عند **فوترة إنفاذ** برقم تدخله المالية |

### جداول التسعيرة (خلف الكواليس — إعدادات)

النظام يضع **أتعاباً متفقاً عليها** من جداول أسعار (قابلة للتعديل من صلاحيات الإعدادات)، حسب نوع الطرف، مثلاً:

- مكتب هندسي — نظير الرفع  
- معاين: فرد / شركة / موظف  
- مراجع حكومي — متعاون فرد  

المشرف قد يطبّق **حسماً**؛ **الصافي** = المتفق عليه − الحسم (ولا ينزل تحت صفر).

## 4) محوران في مالية الشركة

### أ) صادر — أتعاب الأطراف (نلتزم ونصرف)

**من يمرّر المعاملة قبل المالية؟**

| المرحلة | من؟ | ماذا يحدث؟ |
|---------|-----|------------|
| إنجاز العمل | معاين / مكتب / مراجع | الحالة العملية: قيد التنفيذ → مكتملة |
| رفع للاعتماد | الطرف | الأتعاب تنتقل من «مستحق» إلى انتظار المشرف |
| خصم المكتب الهندسي (إن وُجد مسار مراجعة خصم) | المكتب / المشرف | قبول الخصم أو فتح خلاف ثم حسم |
| الاعتماد النهائي للفوترة | **المشرف** | يصبح البند **جاهز للفوترة** لدى المالية |
| إنشاء كشف فوترة | **المالية** | تجميع بنود في كشف رقم مرجعي |
| إصدار الكشف | **المالية** | الكشف «صادر» جاهز للتنفيذ |
| الصرف / الإغلاق | **المالية** | تسجيل الدفع وإغلاق الكشف؛ البنود تصبح **مفوترة / مدفوعة** |

**حالات الدفع بلغة الواجهة (مختصر):**

| ما تراه | المعنى |
|---------|--------|
| مستحق | سجّل الأتعاب؛ لم يصل بعد للاعتماد النهائي |
| بانتظار موافقة المكتب / خلاف تسعير | مسار خصم/خلاف المكتب الهندسي |
| بانتظار اعتماد المشرف | عند المشرف |
| **جاهز للفوترة** | عند المالية — يمكن إدراجه في كشف |
| جاهز — مرحَّل | جاهز لكن المالية أخّرته لدفعة لاحقة |
| مدرج | داخل كشف (مسودة أو صادر) |
| مفوترة / مدفوعة | تمت ضمن صرف/إغلاق |
| مُعاد للتعديل | رجعت للمراجعة (مشرف أو مكتب) |
| استفسار مفتوح | المالية طلبت توضيحاً |
| موقوف | إيقاف حوافز/صرف من المشرف |

**المسار الحي للصرف (المعمول به الآن):**

1. بنود **جاهزة للفوترة**  
2. المالية تختار الطرف/البنود → **إنشاء كشف**  
3. **إصدار الكشف**  
4. عند الدفع: رقم فاتورة خارجي (اختياري) · مرجع إيصال · مرفق تحويل · تاريخ الدفع → **إغلاق/صرف**  

> **ملاحظة:** طريقة قديمة كانت اسمها «أمر صرف» من المكتب لم تعد المسار الأساسي. العمل اليومي للمالية على **كشوف فوترة الأطراف**.

**أمثلة أرقام مرجعية للكشوف:** شكل تقريبي مثل `FN-CS-سنةشهراليوم-تسلسل`.

### ب) وارد — فوترة إنفاذ (نصدر ونحصّل)

| البند لكل عقار | المعنى |
|----------------|--------|
| أتعاب دراسة المعاملة | دخل دراسة الحالة |
| أتعاب / تكاليف الرفع | دخل نظير الرفع |
| أتعاب استلام المفاتيح | يُدخل عند الاستحقاق (غالباً يدوياً من المالية) |
| تضمين في الفاتورة | يمكن استثناء عقار من هذه الجولة |

عند الإصدار يحسب النظام:

- مجموع البنود  
- **ضريبة القيمة المضافة 15٪**  
- الإجمالي  
- رقم فاتورة (يُولَّد للنظام)  
- الحالة: **صادرة** → **تحصيل جزئي** → **محصّلة**

**متى يظهر الأمر في «جاهز لفوترة إنفاذ»؟** عندما تكتمل أو تُغلق معاملات الأمر بما يكفي لاعتباره جاهزاً للفوترة (لا يبقى عقار معلّق يمنع الجاهزية).

## 5) شاشات المالية — ماذا تفتح؟

شاشة **الإدارة المالية** (`/financial`) — تبويبات العمل اليومي:

| التبويب | ماذا تعمل فيه؟ |
|---------|----------------|
| **فوترة الأطراف** | صفوف جاهزة → إنشاء كشف → إصدار → رفع إيصال وصرف/إغلاق · ترحيل غير المختار |
| **فوترة إنفاذ** | اختيار أمر عمل جاهز → تعبئة البنود لكل عقار → حفظ → إصدار فاتورة/PDF → تسجيل التحصيل |
| **استعراض الأطراف** | قراءة ومتابعة بدون إجراء صرف (مرجع) |
| **التقارير** | ملخص إيرادات إنفاذ · تكاليف المزودين · بطاقات (إيرادات، تكاليف خارجية، هامش، مستحقات معلقة) |

شاشات مساعدة يراها غير المالية أيضاً:

| الشاشة | الجمهور | الفائدة |
|--------|---------|---------|
| **الأتعاب والصرف** (`/party-fees`) | مشرف + أطراف | اعتماد، حسم، إعادة، متابعة إنفاذ من زاوية التشغيل |
| **تفصيل العقار → تبويب المالية** | مشرف / مالية / أطراف حسب الصلاحية | نظرة على التزامات الصادر وإيراد إنفاذ لنفس العقار |
| **التسعيرة** (`/fee-pricing`) | إعدادات النظام | تعديل جداول الأسعار الافتراضية |

### بطاقات أعلى لوحة المالية (إن ظهرت)

| البطاقة | القراءة السريعة |
|---------|------------------|
| إيرادات | ما فُوتر لإنفاذ في الفترة |
| تكاليف خارجية | ما يُستحق أو صُرف للأطراف |
| هامش الربح | الإيراد − التكلفة (مفهوم تشغيلي) |
| مستحقات معلقة | ما لم يُصرف بعد |

## 6) من يفعل ماذا؟ (بدون صلاحيات تقنية)

| الدور | دوره في السلسلة المالية |
|-------|--------------------------|
| **أخصائي دراسة / تشغيل** | يستلم أمر العمل، يوزع العقارات والمهام — **لا يصرف** |
| **معاين / مكتب هندسي / مراجع** | ينجز المهمة ويرفع الأتعاب للاعتماد |
| **المشرف** | حسم، اعتماد «جاهز للفوترة»، إيقاف، فك إيقاف، حل خلافات التسعير، متابعة فوترة إنفاذ تشغيلياً |
| **موظف الشؤون المالية** | كشوف الأطراف · فواتير إنفاذ · تحصيل · تقارير · مرفقات إيصالات |
| **الإدارة العليا / من لديه إدارة مالية** | نفس إمكانيات المالية غالباً + رؤية أوسع |
| **مسؤول النظام** | جداول التسعيرة والإعدادات |

**قاعدة ذهبية:** المالية **لا** «تخترع» الأتعاب من الصفر؛ تصلها بنود بعد عمل وقبول واعتماد. يمكنها الإرجاع أو الاستفسار إن وُجدت آلية لذلك على الحالة.

## 7) سيناريو يوم كامل (قصة قصيرة)

1. إنفاذ يعمّد أمر عمل فيه 10 عقارات.  
2. الدراسة تُنشئ المعاملات وتوزّع: 10 معاينات، 7 رَفع، …  
3. كل مهمة مكتملة تولّد سطر أتعاب «مستحق».  
4. الأطراف ترفع للمشرف؛ المشرف يخصم إن لزم ويعتمد → «جاهز للفوترة».  
5. المالية تفتح **فوترة الأطراف**: تختار معايناً وعدة سطور → كشف مسودة → **إصدار** → عند التحويل **إغلاق** برقم إيصال.  
6. بعد اكتمال كل عقارات الأمر: تبويب **فوترة إنفاذ** → إدخال دراسة + رفع (+ مفاتيح إن لزم) → **إصدار فاتورة** بضريبة 15٪ → عند ورود المبلغ **تحصيل**.  
7. التقارير تعرض الإيراد والتكلفة والهامش؛ تفصيل كل عقار يبقى تحت تبويب «المالية» على صفحة العقار.

## 8) مصطلحات سريعة (قاموس عمل)

| المصطلح | المعنى البسيط |
|---------|---------------|
| أمر العمل / PO | ملف التعميد من إنفاذ الجامع للعقارات |
| سجل الأتعاب | إثبات «هذا الطرف يستحق مبلغاً على هذه المهمة» |
| الصافي | بعد الحسم |
| كشف فوترة أطراف | دفعة مجمّعة لأحد الأطراف (مسودة → صادر → مصروف) |
| ترحيل | إبقاء بنود جاهزة لدفعة لاحقة دون إدراجها الآن |
| فاتورة إنفاذ | مطالبة الشركة لإنفاذ عن الأمر/عقاراته |
| التحصيل | تسجيل ما وُصل من إنفاذ مقابل الفاتورة |
| هامش المعاملة | إيراد إنفاذ − التزامات/صرف الأطراف (مفهوم أعمال لا قيد محاسبي كامل) |
| موقوف | لا يُدفع حتى يُرفع الإيقاف |
| رقم خارجي / إيصال | مرجع محاسبة أو بنك يُربط عند إغلاق الكشف |

---

## 9) ما ليس محاسبة كاملة

هذا النظام **يشغّل** التسعير، الاستحقاق، الاعتماد، الفوترة، الصرف، وتحصيل إنفاذ.  
**لا يستبدل** دفتر الأستاذ العام أو برنامج المحاسبة الخارجي.  
غالباً تربط كشف الصرف أو الفاتورة بـ **رقم فاتورة/قيد خارجي** عند الإغلاق.

تقييم العقار (أتعاب المقيّم) **مسار منفصل** ولا يدخل ضمن جداول تسعيرة أطراف المعاينة/الرفع المعروضة هنا.

## 10) قائمة تحقق يومية لموظف المالية

- [ ] **فوترة الأطراف:** هل يوجد «جاهز للفوترة»؟ أنشئ كشوفاً لكل طرف بحسب سياسة الدفع.  
- [ ] كشوف **مسودة** تحتاج إصداراً؟ أصدرها.  
- [ ] كشوف **صادرة** مع التحويل البنكي؟ أغلق مع الإيصال والتاريخ.  
- [ ] بنود تريد تأجيلها؟ **رحّلها** بدل نسيانها في الدفعة الحالية.  
- [ ] **فوترة إنفاذ:** أوامر جاهزة؟ عبّئ البنود، راجع التضمين، أصدر، ثم سجّل التحصيل.  
- [ ] **التقارير:** راقب المستحقات المعلقة والهامش.  
- [ ] أي بند مريب: تنسيق مع **المشرف** (لا تعديل عشوائي بعد الاعتماد دون مسار واضح).

---

*آخر تحديث وصفي مطابق لمسار: أمر العمل → أتعاب بعد التنفيذ والاعتماد → كشف أطراف (مسودة/صادر/مغلق) → فاتورة إنفاذ + تحصيل. مخصص لغير المبرمجين.*
