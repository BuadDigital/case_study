## ٢. قرارات هيكلية

| # | القرار |
|---|---|
| ١ | جميع الأدوار تُسجَّل في **شاشة تسجيل واحدة** — لا وحدة منفصلة للجهات المتعاقدة |
| ٢ | المكتب الهندسي والمعاين المتعاون يُعامَلان **كأفراد** (التعامل كمنشأة مؤجَّل) |
| ٣ | **دور واحد فقط** لكل مستخدم |
| ٤ | **القسم يُشتق تلقائياً من الدور** — حقل `readonly` · استثناء وحيد: المشرف يُختار قسمه · الخارجيون في قسم **الجهات الخارجية** |
| ٥ | **المدير المباشر لا يُسجَّل** — المشرف المسؤول عن أي بند مالي يُشتق من **قسم المعاملة** لا من ملف المستخدم |
| ٦ | المدينة حقل تعريفي — لا تقيّد الوصول ولا التوزيع |
| ٧ | **المحاسب والمالية دور واحد** (`finance`) — يجمع مسؤوليات الجدول ٧ في وثيقة الفوترة |
| ٨ | **لا حذف نهائي** — تعطيل فقط + سجل تدقيق |
| ٩ | **الإشراف يتبع المعاملة لا المستخدم** — البند المالي مرتبط بمعاملة، والمعاملة تتبع قسماً، ومشرف ذلك القسم هو من يحدد الخصم ويحسم الاعتراض. معاين واحد قد تُعتمد بنوده من مشرفَين مختلفَين |
| ١٠ | **التبويب المالي يُفعَّل بخاصية `has_compensation`** لا بالدور — يستوعب إضافة حوافز المقيم لاحقاً بلا تعديل كود |

## ٣. المقيم المعتمد ≠ المقيم العقاري

| | المقيم المعتمد | المقيم العقاري |
|---|---|---|
| الطبيعة | بيانات المنشأة | دور تشغيلي |
| الموقع | إعدادات المنشأة | جدول المستخدمين |
| العدد | سجل واحد | متعدد |
| يُطبع في التقارير | ✅ | ❌ |
| رقم الترخيص وتاريخه | ✅ يُسجَّل هناك | ❌ لا يُسجَّل إطلاقاً |

**للمطور:** لا حقول ترخيص في ملف المستخدم لدور `real_estate_evaluator`.

## ٤. شاشة تسجيل مستخدم جديد

### ٤.١ الحقول الأساسية

| الحقل | المعرّف | إلزامي | ملاحظة |
|---|---|---|---|
| الاسم الرباعي | `full_name` | ✔ | يُطبع في التقارير والخطابات |
| رقم الهوية / الإقامة | `national_id` | ✔ | ١٠ أرقام |
| رقم الجوال | `mobile` | ✔ | **معرّف الدخول** + قناة تحقق |
| البريد الإلكتروني | `email` | ✔ | **إلزامي للجميع** · قناة تحقق — للداخلي بريد الشركة · يُدخله ويغيّره مدير النظام |
| المدينة | `city` | ✔ | تعريفية |
| الدور | `role` | ✔ | واحد فقط |
| القسم | `department` | — | مشتق من الدور · readonly · **المشرف: يُختار** |
| تاريخ الالتحاق | `joined_at` | — | |
| الصورة الشخصية | `avatar` | — | |
| الحالة | `status` | ✔ | بانتظار التفعيل · فعّال · معطّل · مقفل |

### ٤.٢ الحقول الشرطية

| الدور | حقول إضافية |
|---|---|
| **المعاين الميداني** | نوع المعاين: `employee` / `contractor` |
| **المعاين المتعاون** | قيمة الأتعاب · الآيبان · الرقم الضريبي |
| **المكتب الهندسي** | جدول التسعير أو قيمة الاتفاق · الآيبان · الرقم الضريبي · السجل التجاري |
| المشرف · الأخصائي · المقيم · المراجع · المالية | لا شيء |

**بيانات الفوترة تُدخل هنا** — لا في وحدة المالية. وتعديلها بمدير النظام أو المالية فقط (منع احتيال تغيير الآيبان).

### ٤.٣ الدعوة والتفعيل

```
مدير النظام يُنشئ المستخدم
      ↓
رابط دعوة عبر رسالة نصية · صالح ٢٤ ساعة
      ↓
المستخدم يضع كلمة المرور ← تحقق برمز ← الحساب فعّال
      ↓
عرض تفعيل البصمة (اختياري)
```

| البند | القاعدة |
|---|---|
| إعادة الإرسال | مُنشئ الرابط · ومدير النظام دائماً |
| إصدار رابط جديد | يُبطل السابق فوراً |
| رسالة الرابط المنتهي | «هذا الرابط لم يعد صالحاً، تم إرسال رابط جديد إلى جوالك» |

## ٥. قائمة المستخدمين

**النطاق للأدوار العادية: الداخليون فقط** — دليل تواصل. الخارجيون (قسم الجهات الخارجية) يظهرون:
- لمدير النظام والمشرف في القائمة (فلتر «الجهات الخارجية»)
- لبقية الأدوار في **قوائم الاختيار السياقية** داخل إجراءات العمل فقط (إسناد معاملة، اختيار معاين)

### الأعمدة — محتوى متدرج حسب الدور

| العمود | مدير النظام | المشرف | باقي الأدوار |
|---|---|---|---|
| الاسم | ✅ | ✅ | ✅ |
| الدور | ✅ | ✅ | ✅ |
| رقم الجوال | ✅ | ✅ | ✅ |
| الحالة | ✅ | ✅ | ❌ |
| آخر دخول | ✅ | عرض | ❌ |
| الإجراءات | ✅ | ❌ | ❌ |

← لباقي الأدوار: **دليل تواصل**. للإدارة: **أداة إدارة**.

| البند | القرار |
|---|---|
| الفلاتر | الدور · الحالة |
| الإجراءات | تعطيل/تفعيل · إعادة دعوة · فك قفل · فتح الملف |
| مستبعد | القسم (مشتق) · المدينة (بلا منطق) |

**«آخر دخول» في القائمة** يكشف الحسابات المهجورة — مختلف عن سجل الأحداث الذي يعرض كل الدخولات.

## ٦. ملف المستخدم

### ٦.١ الأقسام الأربعة

| # | القسم | المحتوى |
|---|---|---|
| ١ | البيانات الأساسية | حقول التسجيل |
| ٢ | بيانات الدخول | الحالة · آخر دخول · الأجهزة المسجلة · المحاولات الفاشلة |
| ٣ | سجل الأعمال | المعاملات المنجزة |
| ٤ | المالية | **شرطي** — للمعاين والمكتب الهندسي فقط |

**ما استُبعد صراحةً ولا يُبنى:** العهدة · المهام · مؤشرات الأداء · قائمة المعاملات الجارية.

### ٦.٢ مصفوفة الوصول

| القسم | المستخدم نفسه | مدير النظام | المشرف² | المالية |
|---|---|---|---|---|
| البيانات الأساسية | عرض | تعديل | عرض | عرض محدود¹ |
| بيانات الدخول والأجهزة | عرض + إدارة أجهزته | تعديل كامل | **عرض فقط** | ❌ |
| سجل الأعمال | عرض | عرض | عرض | ❌ |
| المالية | عرض + اعتراض | عرض | عرض + تحديد الخصم | تعديل |

¹ الاسم · الدور · بيانات الفوترة — لا الهوية ولا الأجهزة.
² نطاق المشرف: **من يعمل في عملياته** (معاملات قسمه) — لا «من في قسمه». مشرف دراسة الحالة يفتح ملف المكتب الهندسي والمتعاون لأنهم يعملون في عملياته.

**الإجراءات الأمنية** (فك القفل · إعادة الدعوة · إلغاء الأجهزة) — مدير النظام حصراً.

## ٧. سجل الأعمال

**النطاق: لمن مخرجاته تخضع للقبول فقط** — المعاين · المكتب الهندسي · المقيم.
يُخفى للمشرف والأخصائي والمراجع والمالية (لا حدث إنجاز لهم).

**نفس الحدث (قبول المخرجات) يُنشئ سطر السجل والبند المالي معاً — مصدر واحد، عرضان.**

### ٧.١ المنطق

```
أول عمل على المعاملة  →  السجل يبدأ (خفي — يوثّق تاريخ البدء)
        ↓
قبول الأخصائي لمخرجاته  →  يظهر في سجل الأعمال
```

| البند | القرار |
|---|---|
| تعريف «منجزة» | **انتهاء دور المستخدم = قبول مخرجاته** — لا إغلاق المعاملة |
| ما يُعرض | المنجزة فقط · الجارية في شاشة المعاملات |
| السطر | **عرض فقط — غير قابل للفتح** |
| من يراه | المستخدم نفسه · مدير النظام · المشرف |
| عند إعادة المعاملة للتعديل | **السطر يبقى بلا تغيير** — سجل دائم لا يُعدَّل |

### ٧.٢ الأعمدة

| العمود | يُعرض |
|---|---|
| رقم المعاملة / أمر العمل | ✅ |
| تاريخ الإنجاز | ✅ |
| نوع الإسناد (تنفيذ / تركات / خاص) | ✅ |
| المدينة | ✅ |
| **رقم الصك** | ❌ بيانات عقار |
| **اسم المالك** | ❌ بيانات شخصية |

**السبب:** الوصول للمعاملة يُلغى فور قبول المخرجات. عرض بياناتها في السجل التفاف على الإلغاء.

### ٧.٣ الوصول للمعاملة

| الحدث | الأثر |
|---|---|
| قبول المخرجات | يُلغى الوصول فوراً |
| إعادة المعاملة للتعديل | **يُعاد الوصول** مؤقتاً |
| إعادة العمل | تصحيح **بلا أتعاب إضافية** (v1) |

## ٨. التبويب المالي

**النطاق:** يُفعَّل بخاصية `has_compensation` على المستخدم — حالياً: المعاين (موظف ومتعاون) والمكتب الهندسي. المقيم قد يُفعَّل له لاحقاً. يُخفى كلياً لمن لا خاصية له.

**المصدر الوحيد للحقيقة: وحدة المالية.** الملف نافذة عليها.

### مساران مختلفان للخصم — موظف وخارجي

| | الخارجي (متعاون · مكتب) | الموظف (معاين موظف · مقيم) |
|---|---|---|
| طبيعة العلاقة | تعاقدية | إدارية |
| عند الخصم | **موافقة صريحة أو اعتراض** (دورة v1) | **يُبلَّغ فقط — لا اعتراض** |
| مسار البند | بانتظار الموافقة ← جاهز / خلاف تسعير | **جاهز للفوترة مباشرة** بعد اعتماد المشرف |
| حالة «خلاف تسعير» | ممكنة | **لا توجد** |

### ٨.١ البنية

```
التبويب المالي
├── ملخص: المستحق · المدفوع · المتبقي · موقوف
├── البنود  → جدول (٤ أعمدة) + تفاصيل عند فتح الصف
└── الكشوف  → الكشوف الشهرية + مستنداتها
```

### ٨.٢ جدول البنود

| العمود |
|---|
| رقم المعاملة |
| تاريخ الاستحقاق |
| المبلغ المستحق |
| حالة البند |

**تفاصيل الصف:** المبلغ الأساسي · الخصم + سببه · المستحق · المدفوع · المتبقي · حالة الاعتماد · تاريخ السداد · رقم الكشف (رابط) · ملاحظات.

### ٨.٣ حالات البند وألوانها

| الحالة | اللون |
|---|---|
| بانتظار الموافقة | رمادي |
| معترض عليه (خلاف تسعير) | أحمر |
| جاهز للفوترة / مرحَّل | أزرق |
| مدرج في كشف | أزرق |
| مدفوع جزئياً | برتقالي |
| مدفوع | أخضر |
| **موقوف** | مميز |

### ٨.٤ الكشوف

| البند | القرار |
|---|---|
| الكشف | يضم **معاملة واحدة أو أكثر** — لا استثناء في البنية |
| المستندات | الفاتورة · إيصال الدفع — **على مستوى الكشف لا المعاملة** |
| من يرفعها | **المالية** — الطرف لا يرفع شيئاً |
| موافقة الطرف على الكشف | ❌ **اطلاع فقط** (v1) — نقطة الموافقة الوحيدة هي الكشف المبدئي |
| سبب الترحيل | **لا يُعرض للطرف** — يكفي «مؤجّل» |

### ٨.٥ ما يراه الطرف الخارجي

**كل التفاصيل التي تخصه** — بنوده وكشوفه فقط، بما فيها المرحَّلة (شفافية v1).

## ٩. إيقاف الحوافز والاستحقاق

### ٩.١ إيقاف الحوافز (المعاين الموظف)

| البند | القرار |
|---|---|
| من يقرر | **مشرف قسم المعاملة** (الإشراف يتبع المعاملة) |
| المستوى | **معاملة محددة + فترة زمنية** |
| أثناء الإيقاف | تُنشأ البنود بحالة «موقوف» — الأثر محفوظ |
| العرض | **حالة داخل جدول البنود + فلتر** — لا تبويب مستقل |
| الملخص | بطاقة «موقوف» **خارج إجمالي المستحق** |
| رفع الإيقاف | البند **يعود مستحقاً** ويدخل الكشف القادم — **لا يسقط** |

### ٩.٢ إيقاف المعاملة ≠ إيقاف الحوافز

**القاعدة: العبرة بالإنجاز — الاستحقاق يُنشأ دائماً.**

| الحالة | الاستحقاق | المعالجة |
|---|---|---|
| المعاملة أُوقفت **بعد** قبول المخرجات | ✅ قائم | يُصرف عادياً |
| أُلغيت بعد رفع المخرجات وقبل القبول — لسبب لا يخص الطرف | ✅ يُنشأ | يُصرف كاملاً |
| أُلغيت لسبب **يخص الطرف** (خطأ أو تأخير) | ✅ يُنشأ | المشرف يخصم جزئياً أو كلياً (**صفر**) |
| أُوقفت **قبل** إنجاز العمل | ❌ لم يُنشأ أصلاً | — |

**للمطور:** الخصم الكامل = خصم ١٠٠٪ بأداة الخصم القائمة — **لا حالة جديدة**. ويمر بنفس الدورة: وسم + سبب ← المشرف يحدد ← موافقة/اعتراض ← حسم قبل المالية. والبند بصفر **يبقى مسجلاً** موثقاً بسببه.

## ١٠. تبويب مالية المعاملة (اختصار سياقي)

**قاعدة ثابتة: نفس البند — لا سجل مالي منفصل على مستوى المعاملة. الاختصار موضع لا منطق.**

| الدور | الإجراء المتاح |
|---|---|
| الأخصائي | وسم بخصم + سبب (ينفذ باعتماد المشرف) |
| المشرف | اعتماد الوسم · **تحديد قيمة الخصم** · حسم الاعتراض |
| الطرف (معاين / مكتب) | موافقة · اعتراض |
| المالية | عرض فقط |

يعرض أيضاً: المبلغ · الخصم وسببه · المستحق · حالة الاعتماد · رقم الكشف (رابط) · رابط «عرض في ملفي المالي».

## ١١. ملفي الشخصي

| البند | من يملكه | الشرط |
|---|---|---|
| كلمة المرور | **المستخدم** | إدخال الحالية أولاً |
| أجهزة البصمة | **المستخدم** | إضافة وحذف — الحذف الفوري ضروري عند فقد الجهاز |
| الصورة الشخصية | **المستخدم** | — |
| البريد الإلكتروني | **مدير النظام** | قناة تحقق — داخلياً وخارجياً |
| رقم الجوال · الاسم · الهوية · الدور · الحالة | مدير النظام | + سجل تدقيق |
| بيانات الفوترة (الآيبان) | مدير النظام / المالية | منع احتيال |

## ١٢. صلاحيات الحقول

آلية `نموذج ← قسم ← حقل ← دور` بأربع حالات: تعديل · قراءة · مخفي · إلزامي.

**تُضبط على الدور فقط — لا استثناءات فردية.** موظفان بنفس الدور يريان الشيء نفسه دائماً.

## ١٣. إعدادات المنشأة (أساس مبسط — يُفصَّل لاحقاً)

| القسم | الحقول |
|---|---|

| المقيم المعتمد | الاسم · رقم الترخيص · تاريخ الإصدار · تاريخ الانتهاء · فرع التقييم |

**تنبيه إلزامي:** قبل انتهاء ترخيص المقيم المعتمد — انتهاؤه يوقف إصدار التقارير.

الخاضع للتسجيل: إنشاء · تعديل بيانات · تغيير الدور · **تغيير رقم الجوال** · **تغيير البريد** · تعديل بيانات الفوترة · تعطيل · تفعيل · إعادة إرسال دعوة · إلغاء أجهزة · إيقاف/رفع الحوافز · كل خصم واعتراض وحسم وترحيل.

---

## ١٥. أثر التعطيل

| البند | السلوك |
|---|---|
| تسجيل الدخول | يُمنع فوراً |
| الجلسات القائمة | تنتهي بانتهاء سقفها (٣ ساعات كحد أقصى) |
| البيانات المحلية | تُمسح عند أول اتصال |
| سجل الأعمال والبنود المالية | **تبقى** — لا حذف |
