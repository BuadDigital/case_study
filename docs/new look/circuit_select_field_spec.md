# مواصفة حقل اختيار الدائرة — البحث بالرقم

**نظام إجادة** — وحدة المحاكم والدوائر
**الحالة:** توجيه للمطور

---

## 1. الهدف

تقليل زمن الإدخال. المستخدم يقرأ رقم الدائرة من أمر العمل ويكتبه مباشرة، دون التنقل في قائمة منسدلة من ٣٥ عنصراً.

**السلوك المطلوب:** كتابة `5` في الحقل ⟵ تظهر `دائرة التنفيذ الخامسة` فوراً في صدارة النتائج.

---

## 2. مواصفة الحقل

| البند | التفصيل |
|---|---|
| نوع الحقل | Searchable select (combobox) — **وليس** dropdown عادي |
| الإدخال | رقمي بشكل أساسي، مع دعم البحث النصي |
| القيمة المخزّنة | `circuit_id` (مرجع) + `circuit_no` |
| القيمة المعروضة | `circuit_name` (نص عربي كامل) |
| الاعتماد | يُفعَّل بعد اختيار المحكمة فقط |
| الإلزامية | حسب نوع الإسناد — إلزامي في تنفيذ/تنفيذ |

---

## 3. منطق البحث والترتيب

الأولوية بالترتيب:

1. **تطابق رقمي تام** — `5` ⟵ `دائرة التنفيذ الخامسة` (الصدارة دائماً).
2. **بادئة رقمية** — `1` ⟵ `الأولى` أولاً، ثم `الحادية عشرة` … `التاسعة عشرة`.
3. **تطابق نصي** — `خامس` ⟵ `الخامسة`، `الخامسة عشرة`، `الخامسة والعشرون`، `الخامسة والثلاثون`.

### قواعد التطبيع (Normalization)

- تحويل الأرقام العربية الهندية إلى لاتينية: `٥` = `5`.
- تجاهل التشكيل عند المطابقة النصية.
- توحيد الهمزات: `أ` / `إ` / `آ` / `ا`.
- تجاهل `ال` التعريف في بداية كلمة البحث.
- تجاهل المسافات الزائدة.

---

## 4. قواعد العمل

1. قائمة الدوائر **لا تُحمّل قبل اختيار المحكمة** — الحقل معطّل حتى ذلك الحين.
2. تغيير المحكمة يُفرّغ قيمة الدائرة المختارة تلقائياً.
3. الدوائر المعطّلة (`is_active = false`) **لا تظهر** في نتائج البحث، مع بقائها مقروءة في السجلات القديمة.
4. عند الحفظ: يُخزَّن `circuit_id` كمرجع **بالإضافة إلى** snapshot لاسم الدائرة في سجل المعاملة — تعديل الاسم لاحقاً لا يغيّر السجلات السابقة.
5. رقم الدائرة فريد داخل المحكمة الواحدة `(court_id, circuit_no)`.

---

## 5. الـ Endpoint

```
GET /api/courts/:courtId/circuits/selectable
Query: ?q=            # نص البحث (رقم أو نص)
Response: Circuit[] where is_active = true AND court.is_active = true
```

- الترتيب الافتراضي (بدون `q`): تصاعدي حسب `circuit_no`.
- مع `q`: حسب أولوية الترتيب في §3.
- يُفضَّل تحميل الـ ٣٥ دائرة دفعة واحدة عند اختيار المحكمة، وتنفيذ البحث/الفلترة في الواجهة — تجنّباً لطلب شبكة مع كل حرف.

---

## 6. نطاق التطبيق

يُطبَّق هذا الحقل في كل موضع تُدخل فيه الدائرة:

- تسجيل بيانات المحكمة على أمر العمل
- شاشة قرار الإسناد
- إنشاء مهمة زيارة محكمة
- فلاتر البحث والتقارير

**ملاحظة مرتبطة:** مفتاح تجميع خطاب التفويض الداخلي = **المحكمة + الدائرة** معاً، وليس المحكمة وحدها.
