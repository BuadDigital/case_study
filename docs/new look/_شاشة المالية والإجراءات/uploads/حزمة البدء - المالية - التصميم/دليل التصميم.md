# دليل التصميم — نظام دراسة الحالة

**الغرض:** الطبقة البصرية الملزمة. تُنقل مع كل مشروع تصميم جديد بجانب `مرجع منطق المالية.md`.
الملفات المصاحبة: `ui/finance-ui.css` (التنسيقات كاملة) · `ui/logo.svg` · `ui/logo-sidebar.svg`

---

## ١. الهوية

**الشعار:** `ui/logo.svg` — يوضع في أعلى الشريط الجانبي داخل `.brand-card` بعرض 155px، وينكمش إلى 46px عند طي القائمة. النسخة داخل الشريط بيضاء (`fill="#ffffff"`) لأن خلفيته كحلية.

**لا تصمّم شاشة بلا شعار.** إن غاب الشعار فالشاشة غير مكتملة.

---

## ٢. الألوان

نُسخ من `:root` — استخدم المتغيّر لا القيمة المباشرة.

| المتغيّر | القيمة | الاستخدام |
|---|---|---|
| `--ink` | `#102B4E` | الشريط الجانبي · الأزرار الأساسية · العناوين |
| `--navy-3` | `#22406e` | تمرير الأزرار الكحلية |
| `--gold` | `#a4906f` | لون التمييز — الحدود النشطة والفواصل |
| `--gold-d` | `#8c7857` | أرقام الصكوك والمراجع |
| `--gold-2` / `--gold-soft` | `#c8b591` / `#f1ece2` | تدرّجات ذهبية فاتحة |
| `--bg` | `#f5f3ee` | خلفية الصفحة |
| `--surface` / `--surface-2` | `#ffffff` / `#faf8f3` | البطاقات · رؤوس الجداول |
| `--border` / `--border-2` | `#ece8df` / `#ddd8cc` | الحدود الخفيفة والظاهرة |
| `--text` / `--text-2` / `--text-3` | `#3a3f4d` / `#73767f` / `#a4a6ad` | النص الأساسي · الثانوي · الباهت |
| `--heading` | `#102B4E` | العناوين |
| `--row-hover` | `#faf6ee` | تمرير صفوف الجدول |

**ألوان الحالات** (تُمرَّر إلى `pill()`):

| الحالة | اللون |
|---|---|
| محايد / قيد الإجراء | `#102B4E` (NAVY) |
| انتظار / تحذير | `#a4906f` (GOLD) · `#d9a441` للمؤشرات |
| منجز / مدفوع | `#3f8f5f` (GREEN) |
| خطأ / مرفوض | `#c0553d` · النص `#a5432e` |
| معطّل / ملغى | رمادي (GRAY) |
| صفة «فرد» | `#0f766e` |
| مسار خاص | `#6b4bb3` |

**لا تُدخل لوناً جديداً.** إن احتجت تمييزاً، استخدم `color-mix(in srgb, <متغيّر> 8%, transparent)` كما في الكود القائم.

## ٣. الخط والحجوم

**الخط:** `'Tajawal','Segoe UI',sans-serif` — عربي، ووزن 500 هو الأساس و700/800 للعناوين والأرقام.

| العنصر | الحجم |
|---|---|
| عنوان الصفحة | 21px / 800 |
| عنوان بطاقة | 14.5–15px / 800 |
| نص الجدول | 12–12.5px |
| نص ثانوي | 11–11.5px |
| وسم صغير | 9.5–10.5px |
| رقم مؤشر | 19–20px / 800 |

**الأرقام إنجليزية دائماً** مع `dir="ltr"` على الخلية — المبالغ والمراجع والتواريخ والآيبان.

## ٤. المكوّنات الجاهزة

كلها في `ui/finance-ui.css`. استعملها ولا تعد بناءها:

| الصنف | الوصف |
|---|---|
| `.app` | الهيكل: شريط جانبي 260px + المحتوى · `.nav-collapsed` يطويه إلى 68px |
| `aside` · `.brand` · `.nav-group` · `.nav-item` · `.fin-leaf` | الشريط الجانبي وعناصره وعدّاداته |
| `header` · `#pageTitle` · `.crumbs` | الترويسة ومسار التنقّل |
| `.card` | البطاقة البيضاء بحدّ وظل خفيف |
| `.grid` · `.thead` · `.th` · `.row` · `.td` · `.scroll` | الجداول — **العمود الأول يميناً وبقية الأعمدة توسيط** (مفروض بقاعدة CSS) |
| `.status` | وسم الحالة — يُبنى بدالة `pill(نص, لون)` |
| `.kpi` · `.kpi-head` · `.kpi-num` · `.kpi-ico` | شريط المؤشرات |
| `.modal-overlay` · `.modal` · `.modal-head` · `.modal-body` · `.modal-foot` · `.modal-error` · `.tf-lbl` | النوافذ وحقولها |
| `.primary` · `.btn-ghost` · `.ghost-btn` | الأزرار |
| `.empty` | حالة الفراغ |
| `.toast` | إشعار العملية |

**أنماط سطرية ثابتة في الكود:** `INP_STYLE` للحقول · `FIN_SEL_STYLE` للقوائم المنسدلة.

## ٥. قواعد التخطيط

1. **RTL:** `dir="rtl"` على `<html>`، واستخدم `inset-inline-start/end` و`margin-inline-*` لا `left/right`.
2. **الجداول:** رأس ثابت (`position:sticky`) عند طول القائمة، وسقف ارتفاع `calc(100vh - <قدر>)` مع تمرير داخلي — لا تدفع الصفحة.
3. **لا نص مقصوص.** كل عمود يستوعب عنوانه وأطول قيمة فيه.
4. **ضغط ما فوق الجدول** — الترويسة سطر واحد، والفلاتر والأدوات صف واحد.
5. **التبويبات** حبّات دائرية بعدّاد يحصر **القابل للإجراء** فقط.
6. **شريط الخطوات** عند تعدّد المراحل: منجز ✓ أخضر · حالي دائرة كحلية · قادم رمادي.
7. **flex/grid مع `gap`** لا هوامش فردية.

## ٦. كيف تبدأ شاشة جديدة

```html
<!DOCTYPE html>
<html dir="rtl" lang="ar">
<head>
  <meta charset="utf-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1" />
  <link href="https://fonts.googleapis.com/css2?family=Tajawal:wght@400;500;700;800&display=swap" rel="stylesheet" />
  <link rel="stylesheet" href="ui/finance-ui.css" />
</head>
<body>
<div class="app">
  <aside>
    <div class="brand"><div class="brand-card"><!-- ألصق محتوى ui/logo-sidebar.svg هنا --></div></div>
    <nav><!-- عناصر التنقّل --></nav>
  </aside>
  <div class="main">
    <header>
      <div><h1 id="pageTitle">…</h1><div class="crumbs" id="crumbs"></div></div>
    </header>
    <div class="content"><div id="view-generic" class="view"></div></div>
  </div>
</div>
</body>
</html>
```

الشعار يُلصق مضمَّناً (inline SVG) لا عبر `<img>` — ليأخذ لون الشريط ويتقلّص مع الطي.
