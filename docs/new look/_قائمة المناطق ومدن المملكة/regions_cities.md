# قائمة مناطق ومدن المملكة العربية السعودية

**الغرض:** بيانات تأسيسية (Seed Data) لجداول `regions` و `cities` في نظام إجادة.

**الإجمالي:** 13 منطقة إدارية — 148 مدينة/محافظة.

---

## 1. هيكل الجداول

### جدول `regions` (المناطق)

| الحقل | النوع | ملاحظات |
|---|---|---|
| `id` | INT PK | معرف تسلسلي |
| `code` | VARCHAR(4) UNIQUE | رمز المنطقة (RD, MK, ...) |
| `name_ar` | VARCHAR(100) | اسم المنطقة |
| `capital_ar` | VARCHAR(100) | مقر الإمارة |
| `is_active` | BOOLEAN | افتراضي `true` — لا يوجد حذف نهائي |

### جدول `cities` (المدن)

| الحقل | النوع | ملاحظات |
|---|---|---|
| `id` | INT PK | معرف تسلسلي |
| `region_id` | INT FK → `regions.id` | مرتبط بالمنطقة |
| `name_ar` | VARCHAR(100) | اسم المدينة/المحافظة |
| `is_capital` | BOOLEAN | مقر الإمارة |
| `is_active` | BOOLEAN | افتراضي `true` — تعطيل فقط |

**قيد:** `UNIQUE (region_id, name_ar)`

## 3. ملاحظات للمبرمج

1. المدن المعلّمة بـ ⭐ هي مقر الإمارة (`is_capital = true`).
2. القائمة تعتمد التقسيم الإداري الرسمي (13 منطقة + المحافظات التابعة لها).
3. القوائم المنسدلة: اختيار **المنطقة** أولاً ثم تُفلتر **المدن** تبعاً لها (Cascading Select).
4. لا يوجد حذف نهائي — التعطيل عبر `is_active` فقط، مع تسجيل في سجل التدقيق.
5. القائمة قابلة للتوسعة من شاشة الإدارة (إضافة مدينة/حي لاحقاً).
6. ملف البيانات الجاهز للاستيراد: `regions_cities.json`.
