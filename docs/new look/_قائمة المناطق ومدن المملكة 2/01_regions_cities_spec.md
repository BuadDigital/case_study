# مناطق ومدن المملكة العربية السعودية — بيانات تأسيسية (v2)

**الغرض:** Seed Data لجدولي `regions` و `cities` في نظام إجادة.

**المصدر:** القائمة الرسمية للمدن (العنوان الوطني) — مدمجة مع تصنيف المحافظات.

**الإجمالي:** 13 منطقة — 3077 مدينة/قرية/مركز — منها 149 محافظة/مدينة رئيسية.

**⬆️ التغيير عن v1:** استُبدلت قائمة الـ148 مدينة بالقائمة الرسمية الكاملة، مع الاحتفاظ بتصنيف المحافظات كعَلَم `is_governorate`، وإضافة `id` الرسمي و `name_en`.

---

## 1. هيكل الجداول

### `regions` — المناطق (13)

| الحقل | النوع | ملاحظات |
|---|---|---|
| `id` | INT PK | 1–13 (الترقيم الإداري المعتمد) |
| `code` | VARCHAR(4) UNIQUE | رمز مختصر (RD, MK, …) |
| `admin_area_id` | INT UNIQUE | ⬆️ معرّف المنطقة في المصدر الرسمي — للمطابقة عند الاستيراد/التكامل |
| `name_ar` | VARCHAR(100) | اسم المنطقة |
| `capital_ar` | VARCHAR(100) | مقر الإمارة |
| `is_active` | BOOLEAN | افتراضي `true` — لا يوجد حذف نهائي |

### `cities` — المدن (3077)

| الحقل | النوع | ملاحظات |
|---|---|---|
| `id` | INT PK | ⬆️ **المعرّف الرسمي كما هو** — لا يُعاد ترقيمه (غير متسلسل) |
| `region_id` | INT FK → `regions.id` | |
| `name_ar` | VARCHAR(150) | الاسم الرسمي |
| `name_en` | VARCHAR(150) | ⬆️ الاسم بالإنجليزية |
| `name_search` | VARCHAR(150) INDEX | ⬆️ اسم مُطبَّع للبحث (انظر §4) |
| `is_governorate` | BOOLEAN | ⬆️ `true` للمحافظات والمدن الرئيسية (149) |
| `is_capital` | BOOLEAN | مقر الإمارة |
| `duplicate_of` | INT NULL | ⬆️ يشير للسجل الأصلي في حالات التكرار بالمصدر |
| `is_active` | BOOLEAN | افتراضي `true` — تعطيل فقط |

**فهارس:** `INDEX (region_id, is_governorate)` · `INDEX (name_search)`

> ⚠️ لا يوجد قيد `UNIQUE (region_id, name_ar)` — المصدر يحتوي أسماء متكررة لقرى مختلفة داخل المنطقة نفسها. المعرّف الرسمي هو المفتاح الوحيد.

## 4. قواعد البحث والعرض

### تطبيع البحث (`name_search`)
يُطبَّق على المُدخل والمخزون معًا قبل المطابقة:

| القاعدة | مثال |
|---|---|
| حذف التشكيل والتطويل | `أُملُج` → `املج` |
| توحيد الهمزات: أ إ آ → ا · ؤ → و · ئ → ي | `رأس تنورة` → `راس تنوره` |
| ة → ه | `صبيا`, `الغزالة` → `الغزاله` |
| ى → ي | `ليلى` → `ليلي` |
| حذف بادئات: محافظة / مدينة / مركز | `مركز عقلة الصقور` → `عقله الصقور` |
| توحيد المسافات المتعددة | |

### سلوك القائمة في الواجهة

- الافتراضي: عرض **المحافظات والمدن الرئيسية فقط** (`is_governorate = true`) — القائمة الكاملة مربكة للمستخدم.
- عند الكتابة في البحث: توسيع النطاق إلى **كل مدن المنطقة** (`is_active = true`).
- إلزام اختيار المنطقة قبل المدينة (Cascading) — البحث يُقيَّد بـ `region_id`.
- عند تطابق الأسماء داخل المنطقة: عرض الاسم الإنجليزي بجانب العربي للتمييز.
