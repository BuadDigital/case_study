## المرحلة 1 — البيانات الأولية (أخصائي دراسة الحالة / مدخل البيانات)

**الشاشة:** إدخال أمر العمل — نموذج بيانات العقار (`PoPropertyEnfathForm` + تبويبات تفاصيل العقار)

| الحقل | الحالة | ملاحظة |
|---|---|---|
| العميل (من السجل المسبق الإلزامي) | ✅ | القرار 1 — لا إدخال حر |
| مستخدمو التقرير (0..ن) | ✅ | `PoHeaderEdit` — يشتق جملة حصر الاستخدام بثلاث حالات |
| رقم الطلب (مرجع خارجي) | ✅ 🆕 | ق-11: التطابق مع رقم الصك **تحذير أصفر لا منع** |
| رقم التكليف | ✅ | مصدره العميل |
| نوع الإسناد / المحكمة / الدائرة / خطابات التفويض والإسناد | ✅ | |
| تفريغ الصك المنظم: رقم الصك، **نوع الصك (عيني/تقليدي)**، المالك وحصصه، القيود، الحدود والأطوال، المساحة، المخطط/البلك/القطعة | ✅ | القرار 11: الحدود **من الصك** — المساحي أداة مطابقة |
| المدينة / الحي / المنطقة | ✅ | الصك أولاً + إكمال من المستكشف |
| نوع الملكية (مشتق من التفريغ قابل للتحرير) | ✅ | `PoPropertyOwnersSection` — رهن⟵مرهون، حصص⟵مشاع… |
| نوع العقار (مبدئي) | ✅ | **يعتمده المعاين لاحقاً** — الحاكم الشرطي الأول |
| **الغرض من التقييم** (قائمة يختارها المقيّم — §4ج-5) | 🆕 | قرار عمر 2026-08-17: موضعه **إعدادات تقرير التقييم (شاشة 1)** عند المقيّم لا البيانات الأولية — إلزامي، ويطبع في نطاق العمل |

## المرحلة 4 — المعاينة الميدانية (المعاين — عقدة المفتاح)

| نموذج التحقق الميداني: اعتماد **نوع العقار**، الواجهات (٤)، استخدام العقار، حالة العقار/المنطقة/البناء/الإشغال/الحي، المنقولات، مدخل السيارة، قبو/مصعد… | ✅ | القيم متوفر/غير متوفر — «لم يُجب» حالة ثالثة محفوظة |

**الشاشة:** نافذة المقيّم (`/property-appraisal/{task}`) — تبويب «المقارنات» يحوي لوحة العمل الكاملة ✅

| بنك المقارنات (الرافد المكتبي) | كل حقول المقارن: النوع/الاستخدام (قوائم مغلقة) · نوع العملية (منفّذة/عرض) · وصف السعر (حد/سوم) · مرجع الصفقة · رقم الإعلان · الجوال (يُطبع ق-12) · الإحداثيات · **وسوم الجودة بمبرر** | ✅ 🆕 |
| أسلوب السوق | مساحة العقار · أساس التسويات · الاعتماد · التسويات التسلسلية + عوامل الاختلاف (نسبة+مبرر+مفتاح) · الأوزان وتجاوزها بمبرر · تحليل التسويات | ✅ |
| أسلوب التكلفة | استيراد الأرض (ق-4) · تسعير بنود الحصر · غير المباشرة (٦+تمويل) · الأعمار والتقادم بمبرراتها · خصم تقييد الاستخدام | ✅ |
| الرأي النهائي | أساس القيمة (8) · الفرضية (4) · نسب المشاركة بمبرر · خصم التصفية بمبرر · خانات التقريب · مبرر الطرق · التفقيط آلي | ✅ |

| **بند الأخصائي الخارجي** «هل استُعين بأخصائي؟» + التوضيح الإلزامي — في إعدادات تقرير التقييم (شاشة 1)؛ **التمييز صريح**: المقصود الأخصائي الخارجي الذي يستعين به المقيّم لمهام التقييم، لا أخصائي الإسناد ولا أخصائي دراسة الحالة | 🆕 | «لا» ⟵ نفي قياسي في الافتراضات · «نعم» ⟵ التوضيح يحل محله |
| **الافتراضات الخاصة** — المكتبة تُدار في **الإعدادات ⟵ تبويب تقرير التقييم** (قرار عمر 2026-08-17، القرار 25 طبقة ب) والمقيّم ينتقي منها + إضافة حرة؛ النصوص تُجمَّد مع التقييم | 🆕 | نص تحفّظ المعاينة يدخلها آلياً أيضاً |
| **تاريخ التقييم — نوعان** (قرار عمر 2026-08-17): «إصدار القيمة» آلي (غالباً تاريخ إصدار التقرير) · «أثر رجعي» يدوي من المقيّم بتاريخ ومبرر إلزاميين | 🆕 | يطبع في نطاق العمل + سطر الأثر الرجعي في الافتراضات |

## المصبّ الثاني — المخرج المتبقي: تقرير التقييم لدى المقيّم

كل ما سبق يصبّ الآن في محرك العرض (27 قسماً، ~68%) وطبقة حقن المقياس (~94 حقلاً، ~78%). **المتبقي لإكمال المخرج:**

1. **الإصدار ثنائي المرحلة (ق-6)** — نسخة الإيداع المجمّدة ⟵ شهادة قيمة ⟵ النسخة النهائية بصفحة الشهادة *(التالي بعد ق-8)*
2. **ورشة القالب (~7%)**: محرك صفّ الصفحات الكامل · الكليشة ثلاث الشرائح من الإعدادات · أقسام المباني المستقلة · الخرائط من الإحداثيات (Satellite + Map + خريطة المقارنات) · تجميد نص لكل تقرير
3. ~~الغرض · بند الأخصائي · مكتبة الافتراضات · تاريخ التقييم~~ **أُنجزت الأربعة 2026-08-17** — **لم يتبقَّ أي حقل إدخال ناقص من الحزمة**؛ المتبقي طبقة الإخراج فقط (البندان 1 و2)
4. **ق-8 هندسة المبررات** — يخفض نصوص الإدخال قبل تجميد المخرج
5. رقم التقرير — بانتظار ورشة الترقيم (لا يُخترع)

**خلاصة:** الإدخال موزّع ومغطّى بنسبة عالية عبر المراحل الثماني؛ الفجوات المتبقية أربعة حقول إدخال + طبقة إخراج التقرير (البندان 1 و2).
