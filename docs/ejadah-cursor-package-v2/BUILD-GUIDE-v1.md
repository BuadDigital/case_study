## 2. المصطلحات (مسرد لا لبس فيه)

| المصطلح | التعريف |
|---|---|
| **المقياس** | نظام تقييم حالي من **مزوّد خارجي** تستخدمه إجادة الآن — حقوله وقالبه **مرجع تصميم** لبناء نظامنا، وهو **الجاري استبداله** لا منصة تكامل دائمة. «حقن المقياس» = توافق مؤقت أثناء فترة التوازي فقط، وله تاريخ بتر (القرار 17، ق-15). |
| **منصة قيمة** | منصة إيداع تقارير التقييم التابعة **لهيئة المقيمين المعتمدين** — الإيداع فيها **يدوي** على منصة ويب، وهي مصدر **شهادة الإيداع ورمزها** وQR الهيئة. مستمرة قبل التحول وبعده. |
| **إنفاذ** (مركز الإسناد والتصفية) | مصدر **أوامر العمل القضائية**؛ رقم الطلب غالبًا هو الرقم المرجعي للقضية بالمحكمة. **إليه تُرفع الحزمة الشاملة** في الختام. |
| **البورصة العقارية** | مصدر **الاستعلام عن الملكية/الصك**، ومصدر «مرجع الصفقة» للمقارنات المنفّذة. |
| **دراسة الحالة** | الإطار الجامع؛ **التقييم مخرجها الأهم، وتقرير التقييم نفسه تقرير دراسة حالة مهني**. لدراسة الحالة **تقريرها ومرجعها المستقل** عن تقرير التقييم (رقمان متمايزان — القرار 22). |
| **العقار المجمع** | صكوك متعددة لعقار واحد ⟵ **تقرير تقييم واحد جامع** (لا تقرير لكل صك — القرار 18، ق-14). |
| **بطاقة المصدر / provenance** | عرض عند الطلب يبيّن من أدخل القيمة/اشتقّها ومتى وعبر أي قناة — **مشتق من سجل تدقيق واحد** (append-only)، لا مخزن مستقل لكل حقل (ق-15). |
| **توزيع المعاملة** | توزيع المعاملة على **4 أطراف فقط**: معاين، مقيم، مكتب هندسي، أخصائي دراسة الحالة (ق-9). |
| **إسناد المهام** | منظومة **أعم** من توزيع المعاملة — تُسنِد مهامًا لأدوار خارج سير المعاملة (كالمراجع الحكومي). **مستويان معماريان متمايزان: توزيع المعاملة ≠ إسناد المهام** (ق-15أ). |
| **الأصل الحاكم / كما هو** | بناء التقرير مطابقًا للأصل + القرارات المعتمدة فقط؛ أي تطوير خارج ذلك مؤجَّل. |

## 3. فهرس القرارات كمتطلبات مُلزمة

كل صف متطلب محسوم — **لا يُعاد فتحه**. (المرجع: `review-decisions-log-v2.md`؛ ق-N = قرارات المجلس تحت القرار 26.)

| القرار | المتطلب التنفيذي | التفصيل |
|---|---|---|
| **1 — العميل/المستخدم** | العميل مُسجَّل مسبقًا إلزامًا (لا إدخال حر)؛ مستخدمو التقرير 0..ن من السجل ⟵ جملة حصر الاستخدام بثلاث حالات. | السجل §4ج-1 · seed |
| **2 — المالك** | اسم المالك من الصك (تفريغ منظم)، ينساب لموضعيه؛ المالك ≠ العميل. | §4ج-2 |
| **3 — رقم الطلب/التكليف** | رقم الطلب مرجع خارجي (قضية إنفاذ / مرجع العميل / لا شيء)؛ رقم التكليف مصدره العميل. **قاعدة السجل العيني للعقار المجمع تولد من هنا.** | §4ج-3 · القرار 3 |
| **4 — تاريخ المعاينة** | يُختم آليًا من تطبيق الميداني لحظة **إتمام المعاينة** بالموقع (لا الرفع)؛ آخر زيارة مكتملة. | §4ج-4 · ق-10 |
| **5 — الغرض/الأساس/الفرضية** | يختارها المقيّم من القوائم — نوع الإسناد لا يفرضها (إنفاذ قد يكون قيمة سوقية). | §4ج-5 |
| **6 — نوع العقار** | مبدئي من المستندات والعميل، **يعتمده المعاين من الميدان** — حاكم لكل الشرطيات. | §4ج-6 · spec §3 |
| **7 — نوع الملكية** | مشتق من تفريغ الصك (رهن⟵مرهون · حصص⟵مشاع · بلا قيود⟵مطلقة · استثمار يدويًا)؛ نمط «مشتق قابل للتحرير». | §4ج-7 |
| **8 — بيانات الموقع** | الصك أولًا + إكمال من المستكشف + آلية تعارض؛ **حقل «نوع الصك» (عيني/تقليدي)** ركن حاكم للثقة. | §4ج-8 |
| **9 — الاستخدام** | المصدر المستكشف الإلكتروني (بيان الاستخدام التنظيمي)؛ من صك السجل العيني إن وُجد. | §4ج-9 |
| **10 — الإحداثيات** | العقار: المعاين/المقيّم؛ المقارن: مدخل بيانات المنصات. بطاقة المصدر تدوّن مَن والقناة. | §4ج-10 |
| **11 — الحدود والمساحة** | الحدود **من الصك** (مصدر ما يُطبع ويُحسب)؛ الرفع المساحي **أداة مطابقة** لا مصدر بديل؛ الاختلاف **مرشح تعذر** يفحصه أخصائي دراسة الحالة (بوابة جودة قبل الحساب). | §4ج-11 · IVS 106/8-30 |
| **12 — المنقولات** | وصف حر من الميداني؛ الغياب يُدوَّن نفيًا. | §4ج-12 |
| **13 — صيغة التاريخ** | صيغة واحدة YYYY/MM/DD + «هـ» للهجري؛ تخزين معياري وعرض مقولب. | القرار 13 |
| **14 — المرافق/المحيط** | قيم متوفر/غير متوفر يعبّئها الميداني (الفارغ ≠ غير متوفر — حالة تقنية ثالثة محفوظة). | القرار 14 |
| **15 — الأساس والفرضية** | **حقلان مستقلان** مفهومًا وتخزينًا: الأساس (8 قيم) «أي قيمة نقيس»، الفرضية (4 قيم) «في أي ظرف». قاعدة توافق لا احتواء؛ الخصم لا يظهر إلا بأساس قيمة التصفية. | القرار 15 · seed v4 |
| **16 — التنبيهات** | ثلاث درجات: **حاجبة / تحذيرية بمبرر نصي إلزامي / تحذيرية بإقرار**؛ كل مرور يُسجَّل بالتدقيق. الإجمالي بعد ق-4/ق-7 = **21** (7 حاجبة + 8 بمبرر + 6 بإقرار). | القرار 16، 24، ق-4، ق-7 |
| **16أ — تصحيح المصطلحات** | المقياس = مزوّد يُستبدل؛ منصة قيمة = إيداع الهيئة. كل «تعبئة حقول المنصة» يُقرأ بهذا التمييز. | القرار 16أ · spec §8 |
| **17 — سياسة التحول** | موازاة المقياس والنظام حتى النضج؛ إيقاف بثلاثة شروط مجتمعة (مطابقة بصرية + معاملة حقيقية مودعة + اكتمال الحواجب)؛ **الإيداع في قيمة يدوي** ثم إدخال الرمز. | القرار 17، ق-6 |
| **18 — السجل العيني + المجمع** | القاعدة على مستوى **كل صك بحكمه**؛ العقار المجمع **تقرير شامل واحد**. | القرار 18، ق-14 |
| **19 — أربع جودات** | المبررات نص حر؛ تعريفات عوامل الاختلاف بيانات مرجعية بسجل نسخ؛ تجاوز الوزن يستلزم مبررًا؛ دراسة الحالة: خيار «لا ينطبق» + إلزام الملاحظات عند «غير مطابق». | القرار 19 |
| **20 — ربط أوامر العمل** | ثلاث مراحل: **اكتشاف (النظام يقترح) ⟵ تأكيد بشري ⟵ ربط**؛ إشارات الاقتراح: نفس المالك/المخطط + تقارب الإحداثيات (لا تحليل نصوص حدود — ق-15). | القرار 20 |
| **21 — نوع عملية المقارن** | حقل **وصفي** يسترشد به؛ **لا قاعدة إشارة آلية — المقيّم يحدد نسبة التسوية واتجاهها بمبرره**. | القرار 21، ق-2 |
| **22 — رقم التقرير** | **التصنيف محسوم:** تقرير التقييم وتقرير دراسة الحالة مرجعان مستقلان. **الصيغة معلّقة** لورشة الترقيم (لا تخترعها). | القرار 22 |
| **23 — نسخ النصوص** | **نسخة واحدة للحزمة كلها** برقم نسخة واحد؛ قيد العمل يتبنى الجديد والمُصدَر مجمَّد؛ لا إنجليزية الآن. | القرار 23، ق-15ب |
| **24 — حدود المعاينة** | مصطلح واحد؛ مدخلات منظّمة (نطاق/وحدات غير معاينة/سبب)؛ النظام يركّب نص التحفّظ ضمن الافتراضات؛ المعاينة المحدودة **تحذير بمبرر إلزامي**. | القرار 24 · seed v4 |
| **25 — إعدادات المنشأة** | طبقتان: (أ) أصول مشتركة (ختم/توقيع/عضوية) مصدر مركزي واحد يُستهلك في كل المخرجات؛ (ب) تبويب حقول تقرير التقييم وحده. | القرار 25 |
| **26 — قرارات المجلس (ق-1..ق-15)** | عرض الأساس «قيمة التصفية» (ق-1) · نموذج نوع العملية ثنائي هرمي: صفقة منفّذة/عرض ثم وصف السعر حد/سوم (ق-2) · وسوم جودة البنك البشرية (ق-3) · تنبيهان جديدان (ق-4) · **إخفاء ناعم لا حذف** عند انقلاب الحاكمين (ق-5) · **إصدار ثنائي المرحلة** (ق-6) · **حاجب المعاينة المكتبية** (ق-7) · المبرر على مستوى العامل + حد أدنى للطول (ق-8) · **آلة الحالات** (ق-9، §4) · فصل لحظتي المعاينة (ق-10) · رقم الطلب≠الصك تحذير لا منع (ق-11) · جوال المعلن يُطبع (ق-12) · **قاعدة الاختفاء العامة** (ق-13) · نص إحالة لحالة السباق (ق-14) · مرشحات الاستبعاد (ق-15، §5). | القرار 26 · `advisory-board-review-v1.md` |

## 4. آلة الحالات (القرار 9 / ق-9) — مرجع سريع

**شبكة توزيع واعتماديات — لا سلسلة خطية.**

**أ) المراحل التأسيسية (تسلسلية):**
```
[1] ورود أمر العمل من إنفاذ
      ⟵ [2] البيانات الأولية: إدخال بيانات المعاملة (الصكوك) من إنفاذ
            ⟵ [3] الاستعلام من البورصة العقارية (بيانات الملكية والصك)
                  ⟵ [4] التوزيع على الأطراف الأربعة:
                        معاين · مقيم · مكتب هندسي · أخصائي دراسة الحالة
```

**ب) مرحلة العمل (متوازية باعتماديات — المعاين عقدة المفتاح):**
```
        ┌───────────────► المعاين (يعاين ويعتمد نوع العقار ويرفع الصور والبيانات)
        │                        │ ينتظره الجميع
        │        ┌───────────────┼───────────────┐
        ▼        ▼               ▼               ▼
  المكتب الهندسي   المقيّم        أخصائي دراسة الحالة
  (ينتظر تأكيد    (ينتظر بيانات   (ينتظر الجميع ⟵ يطابق الصك/الطبيعة =
   الموقع ⟵ رفع    المعاين وصوره   بوابة الجودة/التعذر ⟵ يكمل دراسة العقار
   مساحي)         ⟵ يسعّر)        والمعاملة)
```
> **المكتب الهندسي مستخدم داخل النظام** (دور جديد يرى مهمته ويرفع الرفع المساحي بنفسه).

**ج) الختام (خطوتان مختلفتا الطبيعة):**
```
[إيداع تقرير التقييم في منصة قيمة]  ← خطوة مهنية تخص تقرير التقييم وحده (ق-6، يدوي)
        ⟵ [رفع حزمة إنفاذ الشاملة]  ← خطوة تسليم شاملة، تضم:
              تقرير التقييم (النسخة النهائية بشهادة الإيداع)
            + تقرير دراسة الحالة (مخرج مستقل — مرجعه مختلف، القرار 22)
            + التقارير المساحية (صك لكل + شامل — ق-14)
            + مستندات وبيانات المعاملة
```

**قاعدة حاكمة:** **حالة المعاملة مشتقة من حالات الأطراف** (لم يبدأ / قيد العمل / معلق بانتظار طرف / مكتمل)، والشاشة تعرض **من ينتظر مَن**.
*(المتبقي لورشة تكميلية: حالات الرجوع/إعادة الفتح ونطاق التجميد على مستوى الحقول — والهيكل أعلاه حاكم.)*

## 5. ⛔ لا تبنِ هذا الآن (المؤجَّلات — مع تعليمة الجذع stub)

هذا القسم يمنع الأسئلة السابقة لأوانها. لكل بند: ما هو، لماذا مؤجَّل، وماذا تبني مكانه الآن.

| المؤجَّل | لماذا مؤجَّل | ابنِ مكانه الآن (stub) |
|---|---|---|
| **الاقتراح الآلي للمقارنات بالقرب الجغرافي** (الرافد الثالث للبنك) | البنك فارغ عند الإطلاق والفائدة ضئيلة أول سنة (ق-15/4) | **فلاتر بحث بسيطة فقط** (حي / نوع / مدى تاريخ / مساحة) + شارة حداثة. لا فهرسة جغرافية ولا ترتيب قرب. |
| **اقتراح تجاور القطع من نصوص الحدود** (للعقار المجمع) | تحليل نصوص حدود عربية حرة — أسابيع وموثوقية منخفضة، والتأكيد بشري دائمًا (ق-15/3) | اكتفِ بإشارتي **نفس المالك + نفس المخطط** (+ تقارب الإحداثيات) و**الربط اليدوي**. |
| **محاكاة قواعد المقياس الشرطية الـ34** (247 رمزًا) | أكبر بند تكامل، يُرمى عند البتر، وتغييرات المقياس تكسره (ق-15/2) | **ربط الحقول المطلوبة فعلًا فقط (~94 لا 247)** لشاشة الرفع، **بلا محاكاة الشرطيات**، مع **تاريخ بتر صريح**. أو إدخال يدوي في المقياس طوال التوازي القصير. |
| **أسلوب الدخل** (رسملة الدخل + القيمة المتبقية) | مؤجَّل رسميًا (السلة الثانية) — العينة أرض | جداوله **شرطية**: تظهر فقط عند تفعيل الأسلوب ووزنه؛ الآن لا تُبنى واجهتها. |
| **OCR / تكامل وزارة العدل لتفريغ الصك** | المرحلة 2 (القرار 7، §4ج-7) | **تفريغ بشري منظم** لحقول كيان العقار (الملاك/الحصص، القيود، الحدود، المساحة). الآلة تقترح والمقيّم يعتمد — لاحقًا. |

## 6. نقاط انتبه لها (أخطاء اجتهاد محتملة)

من تقرير المجلس والسجل — أخطاء يقع فيها المجتهد بلا هذا التنبيه:

- **بطاقة المصدر = عرض عند الطلب، لا مخزن لكل حقل.** تُشتق من **سجل تدقيق حدثي واحد (append-only)**، وتبرز تلقائيًا في **3 مواضع فقط**: اختيار المقارن، الحقول المشتقة القابلة للتحرير، حسم تعارض صك/مستكشف (ق-15/1).
- **المحسوبات لا تُخزَّن.** تُحسب عند الطلب وتُجمَّد **لقطةً عند الإصدار فقط** + يُحفظ معرّف نسخة المحرك لحظة الاحتساب. لا تخزّن التفقيط أو المحسوبات الوسيطة كحقول (ق-15/8).
- **`requiredWhen` موجود في الحقول** (إلزامي شرطي) — لا تعامل كل حقل بإلزام ثابت. أمثلة في seed: «وصف السعر» إلزامي عند نوع العملية=عرض؛ «سبب تقييد المعاينة» إلزامي عند النطاق ≠ كاملة.
- **التقريب مرة واحدة فقط** على القيمة النهائية (رأي القيمة). حقل «عدد خانات التقريب» في مخرجات المقارنة **معطَّل** — لا تقريب وسيطًا قط.
- **الحقل غير المنطبق يختفي كليًا — لا شرطة ولا صف فارغ** (قاعدة الاختفاء العامة ق-13). الشرطة «-» محلها **الوحيد**: الحقل **المنطبق** الغائبة قيمته (كرقم طلب لعميل بلا رقم). والقرار 8ب/12 يُقرأ بهذا: صفوف المباني تختفي من تقارير الأراضي لا تبقى بشرطة.
- **الحذف = إخفاء ناعم لا حذف صلب.** عند انقلاب نوع العقار أو سؤال الإنشاءات: تُخفى بيانات الفرع الساقط وتبقى محفوظة وتعود إن عاد النوع + حوار تأكيد يعرض الأثر + قيد تدقيق + إشعار مُدخِل البيانات (ق-5).
- **رقم الطلب ≠ رقم الصك: تحذير لا منع** — التطابق الحرفي وارد مصادفة (ق-11).
- **نوع العملية للمقارن حقل وصفي فقط** — لا قاعدة إشارة سالب/موجب في النظام؛ المقيّم يحدد النسبة والاتجاه (القرار 21). حصر `field-inventory-v2.md` يفرض قاعدة إشارة ملغاة — تجاهلها.
- **مستندات المعاملة ≠ مرفقات التقرير.** كل ما يرفعه الأطراف يُحفظ في مكتبة المعاملة؛ لا يُطبع في الملاحق إلا ما صنّفه المقيّم وعلّمه «يُطبع في التقرير».
