# منطق طريقة التسويات — أسلوب المقارنات السوقية

> مستخرج من نظام أتمتة إجراءات التقييم العقاري (v3) — وحدة المقارنات.
> المعادلات أدناه منسوخة من الكود المطبَّق فعلياً.

---

## ١. المدخلات

**عن العقار موضوع التقييم**
- `landArea` — مساحة الأرض (م²)

**إعدادات عامة قابلة للتعديل**
- `areaFactor` — معامل المساحة (افتراضي ٥٪)
- `mktRate` — معدل تغير السوق السنوي (افتراضي ٤٪)
- `rounding` — قاعدة التقريب (افتراضي ١٠٬٠٠٠)

**عن كل مقارن معتمد (`sel = true`)**
- `price` سعر المتر · `area` المساحة · `date` تاريخ الصفقة · نوع المقارن (صفقة / عرض / حد / سوم)
- نسب تسوية يدوية: `fin` تمويلية · `mkt` سوقية · `kindAdj` نوع العملية
- ستة عوامل اختلاف يدوية (أدناه)

---

## ٢. تسلسل الحساب

أربع مراحل لكل مقارنة: **تسوية مساحة آلية ← تسويات تسلسلية ضربية ← عوامل اختلاف جمعية ← ترجيح**.

### ٢٫١ تسوية المساحة (آلية بالكامل)

```
r = max(area, landArea) / min(area, landArea)      // دائماً ≥ 1
```

اختيار الطريقة يتم **مرة واحدة لكل الجدول**، لا لكل مقارن:

| الشرط | الطريقة | المعادلة |
|---|---|---|
| أعلى `r` في الجدول ≥ ٢ | المضاعف | `mag = round(log₂ r) × areaFactor` |
| كل قيم `r` < ٢ | الأمثال | `mag = (r − 1) × areaFactor` |

الإشارة تتبع اتجاه الفرق:
- المقارن **أصغر** مساحةً من العقار → سالب
- المقارن **أكبر** مساحةً → موجب
- مساوٍ → صفر

```
areaAdj = sign × mag
```

> تعالج هذه التسوية **الفرق العددي في المساحة فقط**. أما «المساحة المثالية» فعامل يدوي منفصل يعالج قرب المساحة من السائد في الحي.

### ٢٫٢ التسويات التسلسلية (ضربية، بترتيب ثابت)

```
seqPrice = price × (1 + fin/100) × (1 + mkt/100) × (1 + kindAdj/100)
```

1. **التمويلية** — شروط البيع والتمويل
2. **السوقية** — فرق الزمن
3. **نوع العملية** — صفقة منفذة مقابل عرض أو سوم

**التسوية السوقية مقترحة آلياً** من تاريخ الصفقة:

```
months = (اليوم − date) / 30.44
mktSug = round(mktRate × months / 12, 2)
```

أي قيمة يكتبها المقيّم في `mkt` تُلغي المقترح وتحل محله.

### ٢٫٣ عوامل الاختلاف (تُجمع نسبها ثم تُطبَّق دفعة واحدة)

```
factorsSum = areaAdj + Σ(نسب العوامل)
adjVal     = seqPrice × (1 + factorsSum/100)
```

العوامل الافتراضية الستة (القائمة قابلة للإضافة والحذف من الواجهة):

| العامل | يشمل | لا يشمل |
|---|---|---|
| المساحة المثالية | قرب المساحة من السائد للاستخدام في الحي | الفرق العددي في المساحة |
| الموقع | أفضلية الحي أو المنطقة | القرب من معلم، وموضع القطعة داخل الحي |
| عامل الجذب للموقع | القرب من معلم أو مرفق يرفع الطلب | — |
| سهولة الوصول | موضع القطعة داخل نسيج الحي وسهولة بلوغها | عرض الشوارع وعددها |
| عدد الشوارع | عدد الواجهات المطلة | عرضها |
| أطوال الشوارع | عرض الشوارع وأطوال الواجهات | — |

> الحدود مقصودة ألا تتداخل، حتى لا يُحتسب الفرق نفسه مرتين. لكل صف حقل مبرر نصي منفصل.

### ٢٫٤ الأوزان (مقترحة آلياً، قابلة للتجاوز)

القاعدة: **كلما قلّ مجموع التسويات على المقارن ارتفع وزنه** — الأقرب شبهاً هو الأجدر بالثقة.

```
score = 1 / (|factorsSum| + 0.5)
w     = score / Σscores × 100
```

- تُقرَّب الأوزان بطريقة **أكبر البواقي** ليكون المجموع ١٠٠٪ بالضبط دون كسور.
- يستطيع المقيّم كتابة وزن يدوي يتجاوز المقترح، مع زر لإعادة الضبط.
- الثابت `0.5` يمنع القسمة على صفر عند مقارن بلا تسويات، ويحدّ سقف تفوّقه على البقية.

---

## ٣. القيمة النهائية

```
avgPrice     = Σ (adjVal × w / 100)
landValRaw   = avgPrice × landArea
marketValue  = round(landValRaw / rounding) × rounding
```

الناتج سعر متر مرجّح، يُضرب في مساحة العقار، ثم يُقرَّب لأقرب مضاعف لقاعدة التقريب.

هذه القيمة هي **مخرج أسلوب السوق**، وتدخل بعدها في الترجيح النهائي بين الأساليب الثلاثة (السوق والتكلفة والدخل)، وقبل خصم البيع القسري إن وُجد.

## ٤. التنبيهات الرقابية

| المستوى | الشرط |
|---|---|
| خطأ | لا توجد مقارنات معتمدة — يلزم واحدة على الأقل |
| خطأ | مجموع الأوزان ≠ ١٠٠٪ (يظهر عند التجاوز اليدوي فقط) |
| تحذير | مجموع نسب التسويات على مقارن يتجاوز ±١٠٪ — يلزم تدوين المبررات |
| خطأ | تجاوز ±٢٥٪ — يلزم مبرر موثق، ومراجعة صلاحية المقارن أصلاً |

صلاحية تحرير التسويات والأوزان محصورة بدور **مقيم عقاري**؛ ما دونه للعرض فقط.

## ٥. نقاط مفتوحة للنقاش

1. **توحيد طريقة المساحة على مستوى الجدول** — وجود مقارن واحد بنسبة ≥ ٢ يحوّل كل الصفوف إلى المضاعف. البديل: طريقة لكل صف، أو استبعاد المقارن المتطرف بدل تغيير الطريقة.
2. **تقريب اللوغاريتم** — `round(log₂ r)` يجعل التسوية درجات قافزة: نسبة ٢٫٩ و٢٫١ تأخذان الدرجة نفسها. هل يُقصد التدرج أم الاستمرارية؟
3. **خلط الضربي بالجمعي** — التسويات الثلاث الأولى تسلسلية ضربية، وعوامل الاختلاف جمعية. الفرق يظهر عند النسب الكبيرة. مقصود منهجياً أم يُوحَّد؟
4. **معادلة الوزن** — `1/(|Σ|+0.5)` اختيار تجريبي. هل يُعتمد التناسب العكسي، أم معيار آخر كصافي التسويات المطلقة أو عدد العوامل المستخدمة؟
5. **التسوية السوقية الآلية** — تفترض معدل نمو خطي موحد لكل الأحياء والأنواع. هل تُربط بمؤشر سوقي حسب المنطقة والنوع؟
6. **مصفوفة العوامل حسب نوع العقار** — القائمة موحدة حالياً. الفيلا والشقة والتجاري تحتاج عوامل مختلفة (الدور، الواجهة، معدل الإشغال).
